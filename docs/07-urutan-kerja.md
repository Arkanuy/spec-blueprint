## 4. Definisi selesai (per fitur)

- [ ] Perilaku sesuai kebutuhan dan kriteria penerimaan
- [ ] Aturan bisnis ditegakkan di server, bukan hanya di tampilan
- [ ] Kondisi kosong, memuat, dan gagal sudah ditangani
- [ ] Pemeriksaan hak akses ada di server
- [ ] Validasi input ada dengan pesan yang bisa dimengerti pengguna
- [ ] Kasus uji terkait dijalankan dan lulus, dengan bukti
- [ ] Tidak ada kesalahan baru di log
- [ ] Dokumen diperbarui kalau ada yang bergeser
